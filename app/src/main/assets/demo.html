ℹ️ About the Daily Suggestion Worker

The DailySuggestionWorker is scheduled as a PeriodicWorkRequest running daily. It loads users from DietDB, fetches their Profile + BioRecord + 7 days of DishHistory, builds a personalised prompt, calls GemmaAndroidService.computeRecipe(), logs the suggestion, and posts an event for the bridge layer.

Note: The worker has a daily guard (SharedPreferences) that prevents running twice on the same day. If you want to re-test, restart the app or clear the guard.
